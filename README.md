A 4,096-byte chess engine: fixed-depth alpha-beta with quiescence, MVV-LVA move ordering and a centre-weighted evaluation, playing every game through make.fun's trial env.

## Run it

```sh
MAKEFUN_ENV_URL=<the trial env> python3 main.py
```
